# Changelog

Все значимые изменения в проекте YAS-DT документируются в этом файле.

## [2.0.0] - 2024-05-25

### 🎉 Мажорный релиз: Семантический граф знаний

Полная перестройка архитектуры на основе рекомендаций Gemini AI после ревью v1.0.

### ✨ Добавлено

#### Архитектура
- **Нормализованная схема БД** (`scripts/schema.sql`)
  - Таблица `facts` для узлов графа
  - Таблица `fact_relations` для рёбер графа с типизацией
  - Таблица `categories` для категорий
  - Таблица `sections` для секций
  - Индексы для оптимизации графовых запросов
  - Представление `facts_with_stats` для аналитики

#### Типы связей
- 10 типов семантических связей:
  - `causes` - причинно-следственная связь
  - `influences` - влияние
  - `contradicts` - противоречие
  - `supports` - поддержка
  - `derives_from` - происходит из
  - `applies_to` - применяется к
  - `similar_to` - похоже на
  - `part_of` - часть чего-то
  - `prerequisite_for` - предусловие для
  - `related_to` - общая связь

#### TypeScript типы
- `RelationType` - enum для типов связей
- `FactRelation` - интерфейс для типизированных связей
- `YasFactWithRelations` - факт с типизированными связями
- `Category` и `Section` - интерфейсы для метаданных
- `YasCoreV2Structure` - новая структура данных v2.0

#### Скрипты
- `scripts/migrate-v2.ts` - умная миграция с:
  - Дедупликацией по названию
  - Разрешением коллизий ID
  - Извлечением метаданных
  - Построением типизированных связей
  - Атомарной загрузкой данных
- `npm run db:migrate:v2` - команда для запуска миграции

#### Документация
- `ARCHITECTURE.md` - детальная архитектура v2.0
- `QUICKSTART.md` - быстрый старт для новых пользователей
- `CHANGELOG.md` - этот файл
- Обновлён `README.md` с описанием v2.0
- `.env.local.example` - пример конфигурации

### 🔧 Изменено

#### Типы
- `YasFact.relations` теперь опциональное (для обратной совместимости)
- Добавлены новые поля в интерфейсы
- Улучшена типизация для работы с графом

#### Миграция
- Старый скрипт `migrate.ts` сохранён для legacy
- Новый скрипт `migrate-v2.ts` с улучшенной логикой:
  - Умная дедупликация (только настоящие дубликаты текста)
  - Сохранение уникальных смыслов при коллизии ID
  - Автоматическое определение типа связи
  - Подробное логирование процесса

#### Конфигурация
- Улучшен `.gitignore` (добавлены Next.js, IDE, OS файлы)
- Добавлен `.env.local.example` для быстрого старта

### 🐛 Исправлено

#### Проблемы v1.0
- ❌ Плоские связи `relations: number[]` → ✅ Типизированные `FactRelation[]`
- ❌ Всё в одной таблице → ✅ Нормализованная схема
- ❌ Нет семантики связей → ✅ 10 типов отношений
- ❌ Дубликаты ID с разным содержанием → ✅ Умное разрешение коллизий
- ❌ Настоящие дубликаты текста → ✅ Дедупликация по названию

### 📊 Статистика

- **Фактов**: 163+ узлов графа
- **Связей**: Автоматически извлекаются из legacy-формата
- **Категорий**: 7 (Военный, Технология, Психофизика, и др.)
- **Секций**: 8 (Генезис, Военная академия, Рост, и др.)
- **Типов связей**: 10 семантических типов

### 🚀 Производительность

- Индексы на `source_fact_id`, `target_fact_id`, `relation_type`
- Представление `facts_with_stats` для быстрой аналитики
- Оптимизированные запросы для графовых операций

## [1.0.0] - 2024 (Legacy)

### Добавлено
- Базовая миграция с Python на TypeScript
- Скрипт `migrate.ts` для загрузки в Supabase
- TypeScript типы `YasFact`, `YasCoreStructure`
- Настройка Next.js, React, Supabase
- Legacy Python CLI (`legacy/brain.py`)
- Legacy HTML редактор (`legacy/editor.html`)

### Проблемы
- Плоская структура связей без семантики
- Денормализованная схема БД
- Дубликаты ID с разным содержанием
- Нет типизации связей
