# Концепция YAS Digital Twin v2.0

## Философия проекта

> "Любой проект — от семейного дома до ИТ-инфраструктуры — рассматривается как капитальное строение."

### Принципы строительства

1. **Greenfield подход** - Полная перестройка, legacy-код заморожен
2. **Строительство слоями** - Завершаем каждый слой перед переходом к следующему
3. **Наследие строителя** - Никаких временных решений, только масштабируемая архитектура
4. **Семейная песочница** - Изолированное пространство для обучения

## Архитектура данных

### Узлы графа (Facts)

Каждый факт — это узел графа знаний:

```typescript
interface YasFact {
  id: number;              // Уникальный идентификатор
  title: string;           // Название факта
  content: string;         // Полное содержание
  category: string;        // Категория (Военный, Технология, ...)
  section: string;         // Секция (ГЕНЕЗИС, ВОЕННАЯ АКАДЕМИЯ, ...)
  weight: number;          // Вес/важность (0-1)
  age?: number;            // Возраст при событии
  status: 'active' | 'archived';
}
```

### Рёбра графа (Relations)

Каждая связь — это типизированное ребро:

```typescript
interface FactRelation {
  source_fact_id: number;  // Откуда
  target_fact_id: number;  // Куда
  relation_type: RelationType; // Тип связи
  weight: number;          // Сила связи (0-1)
  description?: string;    // Описание связи
}
```

### Типы связей

| Тип | Символ | Описание | Пример |
|-----|--------|----------|--------|
| `causes` | → | Причина-следствие | "Наследие строителей" → "Неприятие костылей" |
| `influences` | ⇢ | Влияние | "Шмидт" ⇢ "Стиль управления" |
| `contradicts` | ↔ | Противоречие | "Быстрый релиз" ↔ "Идеальная архитектура" |
| `supports` | ⇒ | Поддержка | "Трезвость" ⇒ "Ассертивность" |
| `derives_from` | ← | Происходит из | "ROBIUS" ← "Опыт отцовства" |
| `applies_to` | ⇨ | Применяется к | "Метод Шмидта" ⇨ "FlyNav" |
| `similar_to` | ≈ | Похоже на | "Казарма" ≈ "Корпоративный хаос" |
| `part_of` | ⊂ | Часть чего-то | "Deep Work" ⊂ "Психофизика" |
| `prerequisite_for` | ⊢ | Предусловие | "Военная академия" ⊢ "Разведка" |
| `related_to` | ~ | Общая связь | Любая другая связь |

## Алгоритмы

### Дедупликация

```typescript
// Удаляем настоящие дубликаты текста
const seenTitles = new Set<string>();
facts.forEach(fact => {
  const key = fact.title.trim().toLowerCase();
  if (seenTitles.has(key)) {
    return; // Дубликат - пропускаем
  }
  seenTitles.add(key);
});
```

### Разрешение коллизий ID

```typescript
// Если ID занят, но текст уникальный - новый ID
const seenIds = new Set<number>();
let maxId = Math.max(...facts.map(f => f.id));

facts.forEach(fact => {
  if (seenIds.has(fact.id)) {
    maxId++;
    console.log(`Восстановлен смысл! ID ${fact.id} → ${maxId}`);
    fact.id = maxId;
  }
  seenIds.add(fact.id);
});
```

### Построение типизированных связей

```typescript
function inferRelationType(source: YasFact, target: YasFact): RelationType {
  // Анализ контекста для определения типа связи
  if (source.content.includes('основ') || source.content.includes('фундамент')) {
    return 'prerequisite_for';
  }
  if (source.content.includes('влия')) {
    return 'influences';
  }
  if (source.section === target.section) {
    return 'related_to';
  }
  return 'related_to';
}
```

## Визуализация

### Force-Directed Graph

```
Узлы = Факты
  ↓
Физическая симуляция
  ↓
Силы отталкивания (charge)
Силы притяжения (link)
Центрирование (center)
  ↓
Интерактивный граф
```

### Цветовое кодирование

- **Категории** - Цвет узла
- **Вес** - Размер узла
- **Тип связи** - Цвет/стиль ребра
- **Секция** - Кластеризация

## Метрики качества

### Связность графа

```
Средняя связность = Количество связей / Количество узлов
Цель: > 2.0
```

### Плотность графа

```
Плотность = 2 × Связей / (Узлов × (Узлов - 1))
Цель: 0.05 - 0.15
```

### Центральность узлов

```sql
-- Самые важные узлы (хабы знаний)
SELECT id, title, total_relations_count
FROM facts_with_stats
ORDER BY total_relations_count DESC
LIMIT 10;
```
