## Следующие шаги

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка Supabase

1. Создайте проект на https://supabase.com
2. Скопируйте credentials
3. Создайте `.env.local`:

```bash
cp .env.local.example .env.local
# Отредактируйте .env.local
```

### 3. Применение SQL-схемы

Откройте Supabase Dashboard → SQL Editor и выполните:

```sql
-- Содержимое scripts/schema.sql
```

### 4. Миграция данных

```bash
npm run db:migrate:v2
```

### 5. Запуск приложения

```bash
npm run dev
```

Откройте http://localhost:3000

## Типы связей

| Тип | Описание |
|-----|----------|
| `causes` | Причина → Следствие |
| `influences` | Влияние |
| `contradicts` | Противоречие |
| `supports` | Поддержка |
| `derives_from` | Происходит из |
| `applies_to` | Применяется к |
| `similar_to` | Похоже на |
| `part_of` | Часть чего-то |
| `prerequisite_for` | Предусловие |
| `related_to` | Общая связь |

## API Endpoints

### GET /api/facts
Получение фактов с фильтрацией

```bash
curl http://localhost:3000/api/facts?category=Военный
```

### GET /api/graph
Получение графа знаний

```bash
curl http://localhost:3000/api/graph
```
