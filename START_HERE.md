## Быстрый старт (5 шагов)

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка Supabase

1. Создайте проект на https://supabase.com
2. Скопируйте URL и service_role key
3. Создайте `.env.local`:

```bash
cp .env.local.example .env.local
# Отредактируйте .env.local с вашими credentials
```

### 3. Применение SQL-схемы

Откройте Supabase Dashboard → SQL Editor и выполните содержимое файла `scripts/schema.sql`

### 4. Миграция данных

```bash
npm run db:migrate:v2
```

### 5. Запуск приложения

```bash
npm run dev
```

Откройте http://localhost:3000
